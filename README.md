# Shafi Chowdhury profile site

Single-page personal profile site for Shafi Chowdhury, Managing Director of Shafi Consultancy.

- `index.html` is the whole site: plain HTML and CSS, no build step.
- Fonts load from Google Fonts (Ranchers, Space Mono, Plus Jakarta Sans, Archivo).
- The accent colour is the `--accent` variable at the top of the stylesheet.
